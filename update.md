# Syncing the website with the Overleaf manuscript

This site (a Quarto book) is generated by hand from the LaTeX manuscript on Overleaf.
When the manuscript is updated, use this runbook to bring the `.qmd` chapters back in
sync. The whole thing is **detect → sync only what diverged → verify**, so you never
re-translate chapters that haven't changed.

Helper scripts live in `tools/`. Run Python via the project env: `conda run -n mleomaps`.

---

## 0. Get the manuscript

1. On Overleaf: **Menu → Download → Source** (a `.zip`).
2. Unzip it somewhere outside the repo, e.g. a scratch folder. The file that matters is
   `main.tex` (plus `divedeeper.tex` for the appendices); all reference entries live in
   `references.bib`. Note that path — call it `$TEX` below.

```sh
TEX=/path/to/unzipped/main.tex
```

## 1. Detect which chapters diverged

```sh
conda run -n mleomaps python tools/sync_diverge.py "$TEX"
```

This splits `main.tex` at every `\section` / `\subsection`, maps each block to its
`.qmd` (see the mapping table below), and prints a similarity score + **the content
words the manuscript has that the `.qmd` lacks**.

**How to read it:** ignore the raw `sim%`. Look at the *manuscript-only content words*
column and the `<-- CHECK` flag:
- Empty / only LaTeX tokens / the chapter's own title words → **in sync**, skip it.
- Real prose words (nouns, verbs) the `.qmd` is missing → **open that chapter and sync it.**

If the script prints `STRUCTURE MISMATCH`, the manuscript added/removed/reordered a
section or subsection. Update the `MAP` list in `tools/sync_diverge.py` (it's an ordered
list of `(qmd_file, number_of_blocks)`) to match the new structure, then re-run.

## 2. Sync each flagged chapter

For a flagged chapter, read its manuscript block and its `.qmd`, and edit the `.qmd` so
the **content** matches — preserving the existing Quarto formatting. Only change what
actually differs.

Watch for these in particular:
- **`%`-truncation bug from earlier conversions:** a `%` in the LaTeX sometimes cut a
  sentence short in the `.qmd` (e.g. text ending at "30" that should read "30% or
  more..."). Restore the full sentence from the manuscript.
- **Commented-out LaTeX is not content.** Lines starting with `%` were removed by the
  authors — the `.qmd` should not contain them.
- **Renamed headings** → update the `.qmd` YAML `title:` (and see step 4).
- **Tables** are already Markdown; only update cells/rows/captions that changed.

### LaTeX → Quarto conversions (match what the file already does)
| LaTeX | Quarto `.qmd` |
| --- | --- |
| `\citep{a}` / `\citep{a,b}` | `[@a]` / `[@a; @b]` |
| `\citet{a}` / `\citealt{a}` | `@a` (inline author-year) |
| `\ref{fig:x}` / `\ref{tab:x}` | `@fig-x` / `@tbl-x` |
| `\ref{sec:x}` / `\ref{app:x}` | link to the page, e.g. `[EO missions](eo_missions.qmd)` |
| `\footnote{\url{U}}` | `^[<U>]` |
| `\href{U}{T}` / `\url{U}` | `[T](U)` / `<U>` |
| `\textbf{x}` / `\emph{x}` / `\texttt{x}` | `**x**` / `*x*` / `` `x` `` |
| `\paragraph{X}` | bold run-in `**X.**` (or `####` — match the file) |
| `\label`, `\bigskip`, `\noindent`, `\clearpage`, `\resizebox`, tikz/figure scaffolding | dropped |
| inline / display math `$...$`, `$$...$$` | kept as-is |
| `\begin{decision}{T}…\end{decision}` | `::: {.callout-note .box-decision appearance="default" icon="false" title="Decision · T"}` … `:::` (keep the **Alternatives.** / **Trade-off.** / **Constrains.** run-ins, one paragraph each) |
| `\begin{definition}{T}` with `\term{X} text` | `.box-definition`, `title="Definition · T"`; each `\term{X}` becomes its own paragraph starting `**X.**` |
| `\begin{runex}{T}` | `.box-runex`, `title="Running example · T"`; `\textbf{WorldCereal}` / `\textbf{CHM}` lead-ins become separate paragraphs |
| `\begin{sidebar}{T}` | `.box-sidebar`, `title="Dive deeper · T"` |
| `\statusYes` / `\statusPartial` / `\statusNo` | ✓ / ~ / × |
| `\textsc{WorldCereal}` | WorldCereal (plain) |
| `Appendix~\ref{app:x}` | link to the Dive Deeper page, e.g. `[Appendix: Sentinel-1 data gaps](appendix_s1_gaps.qmd)` |

> Tip for large updates: the chapters are independent, so you can hand each chapter
> group to a separate subagent to sync in parallel (that's how the big 2026-07 sync was
> done). Give each agent this file plus its chapter list.

## 3. If the manuscript added new references

`sync_diverge` won't catch missing citations; this will:

```sh
conda run -n mleomaps python tools/sync_citecheck.py
```

Any key it reports as missing needs its BibTeX entry copied from the Overleaf `.bib`
files into this repo's `references.bib`. Re-run until it prints `All citation keys resolve. OK`.

## 4. Feedback form (only if a chapter was renamed)

The "Which chapter?" dropdown in the Tally feedback form and the pre-fill map in
`includes/feedback-prefill.html` both hard-code chapter titles. If you renamed a chapter:
1. Edit the `chapter:` value for that page's `.html` key in `includes/feedback-prefill.html`.
2. In Tally, rename the matching option in the **Which chapter?** dropdown to the exact
   same text, and re-publish. (The two must match character-for-character.)

## 5. Verify and deploy

```sh
conda run -n mleomaps quarto render        # full book; fails loudly on bad refs/citations
```

Then commit and push `main`. The GitHub Actions workflow (`.github/workflows/publish.yml`)
re-renders and deploys to GitHub Pages automatically.

**Website-only additions inside synced chapters.** Some passages cite sources that are
not in the manuscript (e.g. blog posts on inference throughput and cloud processing).
They are wrapped in `<!-- web-only: not in manuscript -->` … `<!-- /web-only -->`
comments. Keep them when syncing a chapter; `sync_diverge.py` only reports words the
manuscript has and the `.qmd` lacks, so they never trigger a flag.
